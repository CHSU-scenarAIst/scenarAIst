## О языке «ЖёПка»

«ЖёПка» — вымышленный функциональный язык программирования со следующими ключевыми особенностями:

1. **Русский синтаксис** — все 47 ключевых слов являются дословным переводом Python (`если` = `if`, `функция` = `def`, `цикл` = `for` и т.д.).
2. **Вложенность через символ «3»** — вместо скобок и отступов. Количество троек = уровень вложенности:
   - `3` — уровень 1
   - `33` — уровень 2
   - `333` — уровень 3
   - Пошаговый переход уровней обязателен (нельзя перепрыгивать с 1 на 3).
3. **Самоимпорт файла** — каждая программа начинается со строки:
   ```
   жёпка принадлежит <имя_файла>.ж
   ```
4. **Иммутабельность по умолчанию** через `пусть`, изменяемое состояние — через `ячейка` с операторами `:=` и `!`.
5. **Функциональные примитивы**: `карта` (map), `функция` (filter), `свёртка` (reduce), `лямбда` (lambda).

## Соглашения о языке

### Русский (только описания и правила)
- Все ключевые слова и операторы языка
- Все текстовые описания в Markdown/HTML/Word/PDF
- Все правила грамматики и сообщения об ошибках

### Английский (только комментарии в коде)
- Комментарии в примерах кода (после `//` или `--`)
- Названия категорий примеров (Classics, Lists, Strings, Recursion, Files, Algorithms)

### Двухязычные элементы
- Таблица операторов (03) содержит колонки как на русском (описание), так и на английском (пример)
- Грамматика (04) использует английские имена нетерминалов (`Program`, `Statement`, `Expression`), но описания на русском

## Ключевые концепции (краткая справка)

### Самоимпорт (обязательная первая строка)
```
жёпка принадлежит привет.ж
3печать("Привет, мир!") // Print greeting to stdout
```

### Вложенность через «3»
```
жёпка принадлежит факториал.ж
3функция факториал(n)
33если n <= 1
333вернуть 1
333конец если
33иначе
333вернуть n * факториал(n - 1)
333конец иначе
33конец функции
```

### Иммутабельность и ячейки
```
жёпка принадлежит счётчик.ж
3пусть x = 10              // Immutable binding
3ячейка y = 0              // Mutable cell
3y := y + 1                // Update via :=
3y ! 5                     // Force-set via !
```

### Функциональные примитивы
```
жёпка принадлежит функциональщина.ж
3карта(лямбда(x -> x * 2), [1, 2, 3])              // map
3функция(лямбда(x -> x > 0), [-1, 0, 1, 2])         // filter
3свёртка(лямбда((a, b) -> a + b), 0, [1, 2, 3])    // reduce
```
