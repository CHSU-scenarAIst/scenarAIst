ЖёПка — Туториал

Функциональный язык с русским синтаксисом и вложенностью через «3». Этот туториал проведёт вас от первой программы до рекурсивных алгоритмов и обработки файлов.

Соглашение о языках

Описания конструкций даны на русском языке. Примеры кода пишутся на русском (поскольку весь синтаксис ЖёПки — русский), а комментарии к коду — на английском, чтобы показать, как читается код международной аудиторией.

ЖёПка — это функциональный язык программирования, в котором исходный код полностью пишется на русском языке. Язык отказывается от скобок и значимых отступов: вместо них каждый уровень вложенности обозначается символом 3, повторённым соответствующее количество раз в начале строки. Каждый файл обязан начинаться строкой самоимпорта жёпка принадлежит <имя>.ж, без которой программа не запустится.

Туториал построен по принципу нарастающей сложности: каждая секция вводит новую концепцию и опирается на предыдущие. К концу вы сможете писать функциональные программы с рекурсией, высшими функциями, обработкой ошибок и файловым вводом-выводом.

Что вы изучите

  • База Структуру файла, самоимпорт, правило вложенности «3»
  • ФП Функции, лямбды, каррирование, иммутабельные связи
  • Продв. Рекурсию, pattern matching, обработку исключений
  • I/O Чтение и запись файлов через контекстные менеджеры

2. Привет, мир!

Минимальная программа на ЖёПке состоит из двух строк: обязательного самоимпорта и вызова оператора печать. Никаких точек входа main, никакой неявной обёртки — код верхнего уровня выполняется последовательно сверху вниз.

привет.ж ЖёПка 
жёпка принадлежит привет.ж
# Print the classic greeting to standard output
печать "Привет, мир!"

Разбор по строкам:

  • Строка 1 — самоимпорт. Имя файла привет.ж должно точно совпадать с реальным именем файла на диске. Без этой строки интерпретатор вернёт ОшибкаСамоИмпорта.
  • Строка 2 — комментарий. Начинается с #, продолжается до конца строки. Комментарии не влияют на уровни вложенности.
  • Строка 3 — вызов оператора печать со строковым аргументом. Выводит значение в стандартный поток вывода.
Запуск программы

Сохраните код в файл привет.ж и выполните: жопка привет.ж. На экране появится Привет, мир!

3. Структура файла

Любой корректный файл ЖёПки имеет следующую обязательную структуру: первая непустая строка — самоимпорт, далее определения верхнего уровня (функции, классы, типы, связи пусть), затем выполняемый код. Порядок определений значения не имеет, поскольку интерпретатор строит полное синтаксическое дерево перед выполнением.

структура.ж ЖёПка 
жёпка принадлежит структура.ж

# === Top-level definitions ===
пусть версия = "1.0.0"

функция приветствие имя
3 печать "Добро пожаловать, " + имя

# === Main execution ===
приветствие "пользователь"
печать "Версия: " + версия

Здесь мы видим четыре ключевых элемента:

  • Самоимпорт в первой строке — обязателен.
  • Связывание пусть — создаёт неизменяемую связь версия со строковым значением. Попытка переприсвоить версия вызовет ОшибкаНеизменности.
  • Определение функции через функция. Имя функции приветствие, один параметр имя. Тело функции находится на уровне 1 (с маркером 3).
  • Вызовы на верхнем уровне — выполняются последовательно после определения.

4. Вложенность через «3»

Главная особенность ЖёПки — отказ от скобок и отступов в пользу явного числового маркера вложенности. Каждая строка может начинаться с последовательности символов 3, и количество этих символов определяет уровень вложенности выражения.

Маркер Уровень Когда использовать
(пусто)0Top-level: определения функций, вызовы
31Тело функции, первый блок условия
332Вложенный блок внутри условия или цикла
3333Двойная вложенность
33334Тройная вложенность

Правила перехода между уровнями строгие: можно увеличивать уровень только на 1 за шаг. Переход с уровня 1 сразу на уровень 3 (через голову уровня 2) вызовет ОшибкаВложенности. После последовательности 3 должен стоять ровно один пробел — табуляция и несколько пробелов запрещены.

вложенность.ж ЖёПка 
жёпка принадлежит вложенность.ж

# Function with nested if/else: 4 levels deep
функция классифицировать n
3 если n > 100
33 печать "большое"
33 если n > 1000
333 печать "очень большое"
3333 вернуть "огромное"
3 иначе
33 печать "маленькое"
33 вернуть "малое"

классифицировать 500
Частая ошибка

Переход с уровня 1 сразу на уровень 3 — самая частая синтаксическая ошибка. Если вам нужно углубиться на 2 уровня, всегда вставляйте промежуточную строку с соответствующим маркером.

5. Переменные и «пусть»

В ЖёПке нет традиционных переменных в императивном смысле. Связывания создаются через пусть и являются неизменяемыми: после того как имя связано со значением, его нельзя переназначить. Это фундаментальное правило функциональной дисциплины, заимствованное из ML-языков и Haskell.

переменные.ж ЖёПка 
жёпка принадлежит переменные.ж

# Immutable bindings via "let"
пусть x = 5
пусть имя = "Анна"
пусть pi = 3.14159

# Type annotations are optional but recommended
пусть счётчик целое = 10
пусть готов логическое = истина
пусть сообщение строка = "Готово"

# Bindings can reference earlier bindings
пусть удвоенный = x * 2
печать удвоенный  # 10

# For mutable state, use "ячейка" (cell)
пусть состояние ячейка = 0
состояние := 42
печать !состояние  # 42

Аннотации типов (целое, строка, логическое) опциональны: интерпретатор выводит типы автоматически. Однако для публичного кода рекомендуется указывать типы явно — это улучшает читаемость и облегчает отладку.

Для изменяемого состояния используется ячейка — изменяемая ссылка в остальном иммутабельном мире. Оператор := присваивает ячейке новое значение, ! разыменовывает её (возвращает текущее значение). Использование ячеек явно помечает код как эффектный.

6. Функции

Функции — основные строительные блоки ЖёПки. Они объявляются через функция, поддерживают каррирование, замыкания и могут передаваться как значения. Тело функции записывается на уровне 1 (с маркером 3).

функции.ж ЖёПка 
жёпка принадлежит функции.ж

# Basic function with one parameter
функция квадрат x
3 вернуть x * x

# Multi-parameter function with type annotations
функция гипотенуза a дробное b дробное вернуть дробное
3 вернуть корень (a * a + b * b)

# Default parameter values
функция приветствие имя фраза = "Привет"
3 печать фраза + ", " + имя

# Currying: partial application returns a new function
функция добавить a b
3 вернуть a + b
пусть добавить_5 = добавить 5
печать добавить_5 10  # 15

# Closures capture their environment
функция счётчик_фабрики начало
3 вернуть лямбда шаг начало + шаг
пусть от_10 = счётчик_фабрики 10
печать от_10 5  # 15

Каррирование работает автоматически для всех функций, объявленных через функция: если вы передаёте меньше аргументов, чем объявлено, возвращается новая функция, ожидающая оставшиеся аргументы. Это позволяет создавать специализированные функции из общих без явного объявления обёрток.

7. Условные выражения

Условия записываются через если, иначе_если и иначе — прямые переводы if, elif, else из Python. Логические операторы переведены как и, или, не; операторы сравнения остались символами.

условия.ж ЖёПка 
жёпка принадлежит условия.ж

# Determine the season by month number
функция время_года месяц
3 если месяц >= 3 и месяц <= 5
33 вернуть "весна"
3 иначе_если месяц >= 6 и месяц <= 8
33 вернуть "лето"
3 иначе_если месяц >= 9 и месяц <= 11
33 вернуть "осень"
3 иначе
33 вернуть "зима"

# Combined condition with "or" and "not"
функция выходной_ли день
3 вернуть день == "суббота" или день == "воскресенье"

пусть сегодня = "среда"
если не выходной_ли сегодня
3 печать "Работаем"

Условные выражения в ЖёПке являются выражениями, а не только операторами: они возвращают значение. Это значит, что вернуть в каждой ветке можно опустить, если использовать условие как правую часть связи:

условие_выражение.ж ЖёПка 
жёпка принадлежит условие_выражение.ж

# Conditional expression returns a value
функция знак n
3 вернуть если n > 0 то 1 иначе_если n < 0 то -1 иначе 0

печать знак -42  # -1

8. Циклы

ЖёПка поддерживает два вида циклов: пока (с предусловием) и для (по элементам последовательности). В функциональном стиле циклы используются редко — предпочтение отдаётся рекурсии и высшим функциям. Однако для утилитарных задач они удобны.

циклы.ж ЖёПка 
жёпка принадлежит циклы.ж

# "для" iterates over a sequence
функция печать_списка элементы
3 для элемент в элементы
33 печать элемент

# "пока" loops with a condition
функция обратный_отсчёт n
3 пусть i ячейка = n
3 пока !i > 0
33 печать !i
33 i := !i - 1
33 если !i == 0
333 прервать
3 печать "Пуск!"

# Range generation (like Python's range)
функция сумма_до n
3 пусть сумма ячейка = 0
3 для i в диапазон 1 n
33 сумма := !сумма + i
3 вернуть !сумма

печать сумма_до 100  # 5050
Функциональная альтернатива

Циклы с аккумулятором — типичный императивный паттерн. В функциональном стиле лучше использовать рекурсию с аккумулятором или высшие функции (свёртка). Это делает код чище и облегчает рассуждение о нём.

9. Функции высшего порядка

Высшие функции — ядро функционального стиля в ЖёПке. Три главных оператора: карта (применяет функцию к каждому элементу), функция (фильтрует по предикату), свёртка (сворачивает последовательность в одно значение).

высший_порядок.ж ЖёПка 
жёпка принадлежит высший_порядок.ж

# "карта" applies a function to every element
пусть числа = список 1 2 3 4 5
пусть квадраты = карта лямбда x x * x числа
печать квадраты  # [1, 4, 9, 16, 25]

# "функция" filters elements by predicate
функция чётное n
3 вернуть n % 2 == 0
пусть чётные = функция чётное числа
печать чётные  # [2, 4]

# "свёртка" reduces a sequence to a single value
функция сложить a b
3 вернуть a + b
пусть сумма = свёртка сложить 0 числа
печать сумма  # 15

# Chaining: filter then map then reduce
функция сумма_квадратов_чётных lst
3 пусть чётные = функция чётное lst
3 пусть кв = карта лямбда x x * x чётные
3 вернуть свёртка сложить 0 кв

печать сумма_квадратов_чётных числа  # 20

В последнем примере показан типичный функциональный паттерн: цепочка функция → карта → свёртка, которая заменяет цикл с условием и аккумулятором. Код читается как декларация намерения: «взять чётные, возвести в квадрат, сложить».

10. Лямбда-выражения

Анонимные функции объявляются через лямбда — аналог lambda в Python. Лямбды удобны для коротких операций, которые не заслуживают именованной функции, и часто используются как аргументы высших функций.

лямбды.ж ЖёПка 
жёпка принадлежит лямбды.ж

# Single-parameter lambda
пусть удвоить = лямбда x x * 2
печать удвоить 21  # 42

# Multi-parameter lambda (supports currying)
пусть сложить = лямбда a b a + b
печать сложить 3 4  # 7

# Lambda as argument to higher-order functions
пусть числа = список 1 2 3 4 5
пусть кубы = карта лямбда x x * x * x числа
печать кубы  # [1, 8, 27, 64, 125]

# Lambda capturing closure variable
пусть множитель = 10
пусть умножить_на = лямбда x x * множитель
печать умножить_на 5  # 50

Лямбды в ЖёПке поддерживают замыкания: они захватывают переменные из окружающей области видимости. Это позволяет создавать функции-фабрики, как показано в последнем примере: умножить_на «запоминает» значение множитель из контекста определения.

11. Рекурсия

Рекурсия — основной инструмент итерации в функциональном программировании. ЖёПка поддерживает прямую и взаимную рекурсию, а также оптимизацию хвостовой рекурсии (в версии 1.0.0 — ограниченную). Рекурсивные функции часто определяются через pattern matching для большей читаемости.

рекурсия.ж ЖёПка 
жёпка принадлежит рекурсия.ж

# Classic factorial — direct recursion
функция факториал n
3 если n <= 1
33 вернуть 1
3 вернуть n * факториал (n - 1)

# Fibonacci — naive O(2^n) for demonstration
функция фибоначчи n
3 если n < 2
33 вернуть n
3 вернуть фибоначчи (n - 1) + фибоначчи (n - 2)

# Tail-recursive sum with accumulator
функция сумма_хвост n аккумулятор
3 если n == 0
33 вернуть аккумулятор
3 вернуть сумма_хвост (n - 1) (аккумулятор + n)

функция сумма n
3 вернуть сумма_хвост n 0

печать факториал 5   # 120
печать фибоначчи 10  # 55
печать сумма 100      # 5050
Хвостовая рекурсия

Функция сумма_хвост — пример хвостовой рекурсии: рекурсивный вызов является последней операцией в теле функции. Это позволяет интерпретатору оптимизировать её в цикл, избегая переполнения стека. Для больших n всегда предпочитайте хвостовую рекурсию прямой.

12. Сопоставление с образцом

Сопоставление с образцом (pattern matching) — мощная альтернатива каскадным если. Оператор сопоставить принимает значение и набор веток; первая подходящая ветка выполняется, остальные игнорируются. Ветки могут содержать литералы, переменные-связывания и деструктуризацию.

сопоставление.ж ЖёПка 
жёпка принадлежит сопоставление.ж

# Define an algebraic data type for shapes
тип Фигура
3 вариант Круг дробное
3 вариант Квадрат дробное
3 вариант Прямоугольник дробное дробное

# Pattern matching on shape variants
функция площадь фигура
3 сопоставить фигура
33 Круг r вернуть 3.14159 * r * r
33 Квадрат s вернуть s * s
33 Прямоугольник w h вернуть w * h

# Pattern matching on literals
функция день_недели n
3 сопоставить n
33 1 вернуть "понедельник"
33 2 вернуть "вторник"
33 3 вернуть "среда"
33 4 вернуть "четверг"
33 5 вернуть "пятница"
33 _ вернуть "выходной"

печать площадь (Круг 5)             # 78.53975
печать площадь (Прямоугольник 3 4)  # 12.0
печать день_недели 3               # среда

Символ _ в последней ветке — wildcard, ловит все остальные значения. Ветка Круг r связывает радиус с переменной r, которую можно использовать в теле. Это эквивалентно деструктуризации, но более читаемо.

13. Обработка ошибок

Ошибки обрабатываются через конструкцию попытка ... перехват ... наконец — перевод try/except/finally. Возбуждение исключений — через исключение (аналог raise). В ЖёПке предопределены типичные исключения: ОшибкаДеления, ОшибкаИндекса, ОшибкаТипа, и другие.

ошибки.ж ЖёПка 
жёпка принадлежит ошибки.ж

# Safe division with error handling
функция безопасное_деление a b
3 попытка
33 вернуть a / b
3 перехват ОшибкаДеления как e
33 печать "Деление на ноль!"
33 вернуть ничто
3 наконец
33 печать "Деление завершено"

# Custom exception type
класс ОшибкаВозраста наследует Ошибка
3 функция __init__ возраст
33 вернуть "Недопустимый возраст: " + возраст

функция проверить_возраст n
3 если n < 0 или n > 150
33 исключение ОшибкаВозраста n
3 вернуть "OK"

попытка
3 проверить_возраст -5
перехват ОшибкаВозраста как e

печать безопасное_деление 10 2  # 5
печать безопасное_деление 10 0  # none

14. Файловые операции

Чтение и запись файлов осуществляется через операторы открыть, читать, писать, закрыть. Для автоматического закрытия используйте с_файлом — аналог with в Python. Режимы открытия: чтение, запись, добавление, чтение_запись.

файлы.ж ЖёПка 
жёпка принадлежит файлы.ж

# Write to a file (manual close)
функция записать_лог сообщение
3 пусть f = открыть "app.log" "добавление"
3 писать f сообщение
3 писать f "\n"
3 закрыть f

# Read with context manager (auto-close)
функция прочитать_конфиг путь
3 пусть содержимое ячейка = ""
3 с_файлом f = открыть путь "чтение"
